# React & Next.js Practice – Learn with Sumit

This repository contains my practice projects, assignments, and mini-apps built while following the **React & Next.js** course by [Learn with Sumit](https://learnwithsumit.com). It's a hands-on journey into modern frontend development using React and Next.js.

---

## 🚀 Technologies Used

- React.js (Hooks, Context, Routing)
- Next.js (Pages, SSR, SSG, API Routes)
- JavaScript (ES6+)
- Tailwind CSS / CSS Modules
- React Query, Axios, SWR (depending on project)
- Firebase / LocalStorage (for some exercises)
